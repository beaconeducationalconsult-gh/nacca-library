## Standalone HTML example review (not public-preview content)

The user added `lesson2-binary-compounds-ph.html` to `main` on 2026-09-24 and provided the existing Vite `index.html` as another reference. The latter is only an app shell. The original standalone chemistry file had no stated reuse license, claimed an unverified B7–B9 mapping, and contained teacher-facing pedagogy, a scored exit quiz with a hard-coded answer map, and chemical-handling/tasting language. **The user chose to sanitize the tracked example on 2026-09-24:** this branch retains its visual controls but removes the quiz/key, teacher plan, misleading curriculum claims and unsafe tasting suggestion, labels pH and indicator colours as approximate, and adds a screen-only safety warning. It remains an *unvalidated design reference*, not approved curriculum. **Do not import or publish it in the Vite bundle.** Only broad, independently implemented layout/interactivity patterns informed the app; chemistry content and source code were not adapted. `npm run build` emits only `dist/`, and `python tools/check_public_build.py` checks that the standalone file and raw packs are absent. Earlier Git history still contains the original file; sanitizing a commit does not erase old Git objects.

## Full school release gate (not satisfied by the public preview)

1. Approved decision record for C1–C7 as applicable, including rights and curriculum edition.
2. Human-checked corrections and structured data imported with provenance and an author/editor sign-off.
3. **Strict normalized-pack validators** for codes, schedule coverage, item/section/component maxima, keys, 5E duration, references, audience filtering and map links. The raw-source baseline is not this validator.
4. Firebase Emulator tests proving assignment-aware reads/writes, learner isolation, no teacher-key leakage and server-only audit; separate dev/staging/production projects.
5. Teacher pilot of exported notes and an offline lesson. None of these exit conditions is met merely by a green “Raw source audit” CI job.
