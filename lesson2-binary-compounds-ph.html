🎯 Learning Objectives
  • Define a binary compound and give 4 examples (NaCl, HCl, MgO, H2O).
  • Write formulae using the criss-cross (valency swap) method.
  • Distinguish ionic (electron transfer) from covalent (electron sharing) bonding.
  • Classify household substances as acidic, neutral or alkaline using indicators.
  • Read the pH scale 0–14 and state the pH meaning of colours.
  • Write the neutralisation equation: HCl + NaOH → NaCl + H2O.
